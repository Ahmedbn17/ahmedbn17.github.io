Write-up : Détection et réponse à une
attaque de Phishing (Lumma Stealer)
1. Contexte et Triage Initial
L'alerte analysée concerne une suspicion de phishing ciblant un utilisateur interne (SOC338
- Lumma Stealer - DLL Side-Loading via Click Fix Phishing).
● Utilisateur ciblé : dylan@letsdefend.io
● Expéditeur suspect : update[@]windows-update[.]site
● Serveur SMTP (IP) : 132[.]232[.]40[.]201
● Objet de l'e-mail : "Upgrade your system to Windows 11 Pro for FREE"
2. Analyse de la Menace et OSINT
L'investigation de l'URL contenue dans l'e-mail révèle une page malveillante imitant une
interface officielle Microsoft Windows 11 Pro. L'attaque repose sur de l'ingénierie sociale : le
site demande à la victime d'utiliser le raccourci "Windows + R", puis de coller un script (Ctrl +
V) et de l'exécuter. Il s'agit d'une technique connue ("Click Fix") pour distribuer le malware
Lumma Stealer.
L'analyse de réputation du domaine windows-update[.]site via VirusTotal confirme la
menace, avec 10 moteurs de sécurité classant l'URL comme malveillante.
3. Investigation des Logs (SIEM)
L'enjeu principal est de déterminer si l'utilisateur a cliqué sur le lien et exécuté la charge
utile. La recherche dans le SIEM (Log Management) sur le domaine suspect a permis
d'isoler une requête réseau critique :
● URL accédée : [hxxps[://]windows-update[.]site/](hxxps[://]windows-update[.]site//)
● Referrer : [https://mail.letsdefend.io/](https://mail.letsdefend.io/) (prouve que le clic
provient du webmail interne)
● Statut HTTP : 200 OK (indique que la connexion a réussi et que la page a été
chargée)
4. Remédiation et Conclusion
True Positive
● Incident: The user Dylan (172.16.17.216) received a phishing email from
update[@]windows-update[.]site (SMTP: 132[.]232[.]40[.]201) luring him with a fake
Windows upgrade.
● Evidence: Network logs confirm the user clicked the link and successfully accessed
the malicious domain.
● Action Taken: The host machine was immediately isolated (contained) to prevent
malware execution, lateral movement, and data exfiltration.
